# 汉字闪练 Product Definition Document

- **English working title:** AP Chinese Flash Cards
- **Status:** Approved product design
- **Date:** 2026-09-05
- **Target:** MVP
- **Platform:** Local-first Progressive Web App (PWA)

## 1. Product summary

汉字闪练是一款面向 AP 中文备考学生的本地优先字卡应用。它通过随机、不放回的字卡练习，帮助学生识别 AP 中文场景中的高频汉字、练习读音、纠正错字，并把字分入多个学习字库。

MVP 无需账号或服务器。学习内容、标签和统计保存在当前浏览器中，可通过 JSON 和 CSV 导入导出。应用支持安装为 PWA，并在内容缓存后离线复习；浏览器提供的语音识别可能仍需联网。

## 2. Product goals

1. 内置产品整理的“AP 备考常用 1000 字”。
2. 用户无需注册，打开应用即可选择字库开始复习。
3. 支持随机、不放回出题，以及鼠标、键盘和语音翻面。
4. 支持浏览器语音识别的近似严格判定，并允许用户覆盖自动结果。
5. 支持用户添加、修改、删除字卡，以及维护多个非互斥字库。
6. 页面关闭或浏览器重启后，字库、学习状态与统计保持完整。
7. 支持完整备份、恢复和批量编辑。
8. 初始 1000 张卡都具有完整学习内容，而不是占位数据。

## 3. Target users

### Primary user

正在准备 AP 中文考试、希望独立练习识字和读音的学生。

### Future users

教师和家长以后可查看多名学生的学习进度。MVP 不实现账号、班级、共享字库或监护人仪表盘，但数据边界不得阻碍以后增加这些能力。

## 4. MVP scope

### Included

- 简体中文。
- 七个可选择的字库。
- 已复习系统状态与轮次统计。
- 随机、不放回的字卡学习。
- 点击、空格键和“翻”语音命令。
- 浏览器语音识别及结果展示。
- 自动与手动正确/错误判定。
- 字卡内容和字库成员管理。
- 多行文本批量提取汉字。
- 本地持久化、PWA 安装和内容离线使用。
- JSON 完整备份与恢复。
- CSV 内容导入与导出。
- 基础累计统计和每轮汇总。

### Excluded

- 登录、云同步和服务器端用户数据。
- 教师、家长和班级管理。
- 专业声调音高分析或发音评分服务。
- 繁体中文。
- AI 在线生成内容。
- 排行榜、社交、广告和付费功能。
- 长期保存录音或原始语音识别记录。

## 5. Vocabulary libraries

用户可以从以下七个字库中选择出题来源：

1. **全部字库**：所有有效字卡的集合。
2. **未复习字库**：当前大轮次中还未出现的字。
3. **错字库**：最终判定为错误的字。
4. **生词库 1**：用户标签。
5. **生词库 2**：用户标签。
6. **生词库 3**：用户标签。
7. **熟词库**：用户标签。

“已复习”是系统状态和统计维度，不是第八个用户标签字库，也不作为首页的出题字库。

### Membership rules

- 同一个字可以同时属于多个不同字库。
- 单个字库内部不允许出现重复字。
- 各字库只保存对主字卡的引用，不复制字卡内容。
- 在任意位置修改字卡内容后，所有字库中的该字均显示最新内容。
- 向已有该字的字库重复添加时不产生第二个成员。
- 错字、生词 1/2/3 和熟词不是互斥分类。

### Unreviewed lifecycle

- 首次初始化时，未复习字库包含全部字库中的所有字。
- 一张卡首次在任意来源字库的学习会话中出现时，该字即从未复习字库移除，并进入已复习状态。
- 此移动发生在卡片出现时，而不是判定对错或点击下一张时。
- 未复习字库清空后，系统先显示本轮摘要，不立即重置。
- 用户确认“开始新一轮”后，系统用当时全部字库中的所有字重新填充未复习字库。
- 重置未复习字库不清除标签、累计统计或历史轮次摘要。
- 新增到全部字库的字自动加入未复习字库。
- 从全部字库删除的字同时从未复习和所有标签字库移除。

## 6. Flash card content

每张主字卡包含：

- 一个简体汉字。
- 一个或多个标准拼音。
- 多音字每个读音对应的简短含义。
- 简短英文释义。
- 最多 6 个 AP 场景常用词组，每个词组包含汉字、拼音和英文释义。
- 如果该字不适合组成自然且常用的词组，则使用两个自然、适龄的中文例句，并提供拼音和英文翻译。
- 内置内容版本号和字段级用户编辑标记。

### Initial 1000-character collection

- 字表名称为“AP 备考常用 1000 字”或含义相同的产品整理字表。
- 不得称其为 College Board 官方指定字表。
- 选字综合 AP 中文主题覆盖、考试常见语境和现代汉语使用频率。
- AP 主题至少覆盖家庭与社会、学校生活、个人身份、科技、环境、健康、旅行、文化传统、艺术、经济和全球议题。
- 发布前必须完成内容审核：无待核对项；拼音含声调符号；英文释义简洁；词组或例句自然；不存在空字段和重复主字卡。

## 7. Primary user flows

### 7.1 Start a study session

1. 首页显示七个字库、字数和必要的进度信息。
2. 用户选择一个非空字库。
3. 系统创建该会话的字卡 ID 快照并打乱顺序。
4. 本轮按打乱后的顺序出题，不放回抽取。
5. 如果存在未完成会话，首页提供“继续上次学习”。

### 7.2 Review a card

1. 正面只显示目标汉字和简短操作提示。
2. 卡片显示时立即更新该字的未复习/已复习状态。
3. 用户可以朗读目标字。
4. 点击卡片、按空格键或说“翻”后，卡片翻到背面。
5. 背面显示拼音、英文释义、词组或例句。
6. 自动判定结果显示为对号或错号，并展示识别到的文字。
7. 用户可以手动将结果改为正确或错误。
8. 用户可以添加或移除错字、生词 1/2/3、熟词标签；重复操作保持幂等。
9. 判定后卡片停留在背面，不自动跳转。
10. 用户点击“下一张”后继续。

### 7.3 Complete a session

- 会话快照中的每张卡完成一次后显示摘要。
- 摘要至少包含本轮卡数、正确数、错误数和正确率。
- 如果未复习字库已清空，摘要提供“开始新一轮”操作。
- 若学习来源不是未复习字库，会话结束不自动改变其他字库成员关系。

## 8. Correct and incorrect state

- 自动语音判定或首次手动判定产生该卡本次作答结果。
- 用户可以在离开当前卡之前修改结果。
- 当前卡只在点击“下一张”时最终结算一次，避免多次点击导致统计重复累加。
- 最终结果为错误时，字卡加入错字库。
- 最终结果为正确时，字卡从错字库移除，包括自动判对和用户由错改对。
- 人工修改后的结果优先于语音自动结果。
- 从错字库移除不会清除该字过去的累计错误次数。

## 9. Speech behavior

### Pronunciation assessment

MVP 使用浏览器 Web Speech Recognition 能力进行近似严格的文字匹配：

- 识别结果与目标汉字及卡片允许的读音对应时，自动标记正确。
- 识别为其他字或明确不同的结果时，自动标记错误。
- 多音字接受该卡已列出的合法读音或对应识别结果。
- 识别超时、无结果或置信度不足时不直接判错，要求用户手动选择。
- 界面必须说明该功能不能可靠测量声调音高，不是专业发音评分。
- 用户可看到本次识别到的文字，但应用不长期保存该文本。

### Voice command “翻”

- 在学习页且卡片为正面时，听到“翻”会翻到背面。
- 卡片已在背面时，“翻”不进入下一张，也不更改判定。
- 持续监听“翻”应为明确可见、可关闭的学习设置。
- 朗读判定和“翻”命令的监听状态必须在界面上可见。

### Fallback

- 优先支持当前稳定版 Chrome 和 Edge。
- 浏览器不支持语音、麦克风未授权或识别失败时，所有非语音学习功能保持可用。
- 应用隐藏或禁用不可用的语音操作，并给出简短、可执行的说明。

## 10. Character management

管理页支持搜索、筛选、添加、编辑、删除和批量调整字库成员关系。

### Add one or many characters

点击“添加汉字”打开编辑框：

1. 用户可以输入或粘贴一行或多行文本。
2. 系统按 Unicode 汉字范围提取汉字，忽略标点、数字、拉丁字母、空白和其他非汉字字符。
3. 输入中重复出现的汉字只保留一次，并保持首次出现顺序。
4. 已存在于全部字库中的字不再次加入。
5. 添加前实时展示“将添加”“已存在”和“忽略的非汉字字符”数量，并预览要加入的字。
6. 确认后，新字加入全部字库和未复习字库。
7. 新字缺少拼音、释义和学习内容时标记为“内容待完善”，在完善前允许管理，但不得进入普通学习会话。

### Edit a character

- 支持编辑汉字、拼音、英文释义、词组和例句。
- 修改主汉字时执行与新增相同的唯一性检查。
- 如果目标汉字已经存在，阻止保存并引导用户编辑已存在的字卡；MVP 不自动合并两张主字卡。
- 内置字段被用户修改后标记为用户编辑，后续内容版本升级不得静默覆盖。
- 可恢复单张内置字卡的原始内容，操作前需要确认。

### Delete a character

- 删除前显示二次确认。
- 删除后从全部字库、未复习状态和所有标签字库移除，并删除该字统计。
- MVP 不提供应用内回收站；用户可通过先前导出的完整备份恢复。

## 11. Import and export

### JSON

JSON 是完整备份格式，包含数据模式版本、所有主字卡、用户编辑字段、字库成员关系、未复习状态、累计统计、轮次摘要和应用设置。

导入流程必须先完整验证，在单一事务中写入。写入失败时保留导入前数据库。覆盖前展示新增、更新、跳过和无效记录数量，并要求用户确认。

### CSV

CSV 用于查看和批量编辑字卡内容，不作为完整学习进度备份。CSV 导入支持主字、拼音、英文释义、词组和例句字段。字库成员、学习统计和设置以 JSON 为准。

## 12. Statistics

每个字保存累计复习次数、累计正确次数、累计错误次数、正确率和最后复习时间。正确率按正确次数除以已结算复习次数计算。

每个已完成或主动结束的学习会话保存：会话 ID、来源字库、开始与结束时间、已完成卡数、正确数、错误数和正确率。

MVP 不保存每次识别的原始音频、完整识别文本或逐题永久事件日志。

## 13. Information architecture and screens

### Home

- 七个字库及当前字数。
- 未复习总体进度。
- 继续未完成会话。
- 进入字库管理和设置。

### Study

- 来源字库、当前序号和本轮正确率。
- 居中的主字卡。
- 麦克风/监听状态。
- 正确、错误、标签和下一张操作。
- 识别结果及判定原因。

### Library management

- 搜索汉字、拼音或英文释义。
- 按字库和内容完整性筛选。
- 添加汉字、编辑、删除、批量标签。
- JSON/CSV 导入导出。

### Round summary

- 本轮完成数、正确数、错误数和正确率。
- 返回首页或再次学习。
- 未复习清空时提供“开始新一轮”。

### Settings

- 开关持续监听“翻”。
- 语音功能状态和权限说明。
- 数据备份提醒。
- 恢复默认设置；不得与删除全部学习数据混为同一操作。

## 14. Suggested technical architecture

实现代理可调整具体框架，但必须保持以下边界：

1. **Presentation layer**：响应式 PWA 页面、键盘和触摸交互、无障碍状态。
2. **Study engine**：会话快照、随机打乱、不放回推进、结算和重置规则。
3. **Library service**：主字卡唯一性、字库集合、标签幂等操作和未复习生命周期。
4. **Speech adapter**：封装浏览器语音识别、权限、超时、结果正规化和能力检测。
5. **Persistence layer**：IndexedDB 模式、事务、迁移、导入导出和回滚。
6. **Seed content**：版本化的 1000 字静态数据，独立于用户编辑记录。
7. **Service worker**：应用壳和种子内容缓存；不缓存或保存用户录音。

业务规则应实现为无界面的纯函数或独立服务，使随机会话、判定覆盖、去重和重置逻辑可以在没有浏览器 UI 的环境中测试。

## 15. Conceptual data model

### `CharacterCard`

- `id`: 稳定内部 ID。
- `character`: 唯一简体汉字。
- `readings[]`: 拼音、含义和可接受识别形式。
- `englishMeaning`。
- `contentType`: `compounds` 或 `examples`。
- `compounds[]`: 最多 6 个词组。
- `examples[]`: 使用例句模式时恰好 2 个。
- `contentStatus`: `complete` 或 `needs_content`。
- `seedVersion`。
- `userEditedFields[]`。
- `createdAt`、`updatedAt`。

### `LibraryMembership`

- `libraryId`。
- `characterId`。
- `(libraryId, characterId)` 必须唯一。

### `ReviewState`

- `characterId`。
- `isUnreviewed`。
- `reviewCount`、`correctCount`、`incorrectCount`。
- `lastReviewedAt`。

### `StudySession`

- `id`、`sourceLibraryId`。
- `cardIds[]`: 会话开始时的打乱快照。
- `currentIndex`。
- 当前卡尚未结算的临时判定。
- 汇总计数和开始/结束时间。
- `status`: `active`、`completed` 或 `ended`。

### `AppSettings`

- 持续监听“翻”的开关。
- 数据备份提醒状态。
- 应用和数据库模式版本。

## 16. Error handling

- 麦克风未授权时不反复请求权限；展示开启方法。
- 不支持语音的浏览器显示手动模式提示。
- 无结果、超时或低置信度语音不自动判错。
- 空字库不进入空白学习页，提供返回和添加操作。
- 重复添加保持幂等。
- 存储不足或写入失败时不得显示成功状态，并提示导出备份。
- JSON 导入在事务中执行，失败时回滚。
- 数据库升级前保留可回滚状态，迁移失败继续使用兼容的旧数据。
- Service Worker 更新失败时继续运行当前已缓存版本。
- 删除浏览器站点数据会清除本地记录；产品应在适当时机提醒备份。

## 17. Accessibility and responsive behavior

- 所有核心操作必须可通过键盘完成。
- 空格键只在焦点未处于文本输入控件且学习卡正面显示时翻面。
- 操作控件使用可见标签或无障碍名称，焦点状态清晰。
- 正确/错误不能只依赖颜色，必须同时使用文字和符号。
- 动态语音与判定状态通过适度的 live region 通知，不朗读连续音频变化。
- 支持 320 px 宽度及以上的手机界面，并适配桌面。
- 触摸目标建议至少约 44 × 44 CSS 像素。
- 尊重 `prefers-reduced-motion`；禁用翻卡动画时仍立即切换内容。

## 18. Privacy and security

- 默认不创建账号，不上传学习数据。
- 不长期保存录音或识别文本。
- 明确说明浏览器语音服务可能把音频发送给浏览器供应商进行识别。
- 导入内容视为不可信数据；显示时转义文本，不执行其中的标记或脚本。
- 导入文件必须限制类型和合理大小，防止浏览器内存耗尽。
- PWA 和数据导出不得包含 API 密钥。

## 19. Acceptance criteria

### Libraries and sessions

- 首次运行时全部字库和未复习字库均包含 1000 个完整、唯一汉字。
- 同一字可以同时属于多个标签字库，但同一字库中最多出现一次。
- 从任意字库显示一张卡后，该字立即从未复习字库移除。
- 会话内每个字最多出现一次。
- 未复习字库清空后，只有用户确认才重新填充。
- 新一轮重置不清除累计统计和标签。

### Cards and decisions

- 正面只显示字；背面显示规定的学习内容。
- 点击卡片和符合条件的空格键均可翻面。
- 最终判错会加入错字库；改为正确会从错字库移除。
- 对同一当前卡多次切换对错，只在进入下一张时结算一次。
- 判定完成后不会自动跳转。

### Speech

- 支持时可识别读音并显示识别文本与自动结果。
- “翻”只将正面翻到背面。
- 不支持或未授权语音时，手动学习完整可用。
- 产品不宣称能可靠评估声调音高。

### Character management

- 多行输入只提取汉字，保持首次出现顺序，并去除输入内重复字。
- 已存在于全部字库中的字不会重复加入。
- 新字同时进入全部字库和未复习字库。
- 修改一张主字卡后，各字库显示一致内容。
- 删除会清理所有字库成员关系和该字统计。

### Persistence and portability

- 刷新、关闭并重新打开应用后，数据保持一致。
- JSON 导出后清空本地数据，再导入该文件，可以恢复字卡、标签、未复习状态、统计、会话摘要和设置。
- 无效导入不会部分修改现有数据库。
- 安装后的 PWA 在应用资源已缓存且断网时仍可手动复习。

### Content quality

- 种子数据恰好包含 1000 个唯一简体汉字。
- 所有种子字卡具有至少一个带声调拼音和英文释义。
- 每张种子字卡要么有 1–6 个完整词组，要么有恰好 2 个完整例句。
- 自动验证不得发现重复字、空必填字段、超过 6 个词组或不符合内容模式的记录。

## 20. Testing expectations

### Unit tests

- 字库幂等添加和跨字库成员关系。
- 多行汉字提取、非汉字过滤、去重和顺序保持。
- 打乱结果的集合完整性和会话内不重复。
- 未复习移动与新一轮重置。
- 最终判定覆盖和一次性统计结算。
- 多音字识别结果正规化。
- 种子内容数据验证。
- JSON 模式验证和迁移。

### Integration tests

- IndexedDB 创建、事务、升级、失败回滚和恢复。
- 会话中断后的继续学习。
- 新增、编辑、删除对所有字库视图的同步影响。
- JSON 完整往返和 CSV 内容导入。
- 语音适配器在支持、不支持、拒绝权限、超时和低置信度情况下的行为。

### End-to-end tests

- 从首页选择字库，完成朗读、翻面、判定、标签和下一张流程。
- 完成未复习字库并确认开始新一轮。
- 批量粘贴混合文本并验证只添加唯一汉字。
- 手动纠正自动判定并验证错字库与统计。
- 桌面和窄屏移动布局的关键路径。
- 离线启动和手动复习。

## 21. Release readiness

MVP 可发布的前提：

- 所有验收标准通过自动化或明确记录的人工测试。
- 1000 字内容完成自动校验和人工抽样审核。
- Chrome 与 Edge 完成语音和权限测试；其他浏览器完成手动模式测试。
- JSON 备份恢复在干净浏览器配置中验证通过。
- PWA 安装、升级、离线启动和数据迁移验证通过。
- 产品内明确显示本地存储和语音隐私说明。
